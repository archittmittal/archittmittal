## Featured Projects

### Clinical Risk Predictor
Machine learning model trained on clinical data of Type 2 Diabetes patients.  
Predicts risk using glucose, BMI, age, insulin, and blood pressure.  
Built with Python, Pandas, NumPy, and Scikit Learn.

### Eco Vyapaar
Digital platform for local vendors to sell online.  
Focus on ethical commerce and vendor accessibility.

### Food Waste Management System
Platform that connects food donors with NGOs and gaushalas.  
Includes expiry validation and location matching.

### Supermarket Billing System
Console based billing system.  
Supports inventory tracking and transaction logging.
